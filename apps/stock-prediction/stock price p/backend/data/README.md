# Stock Price Dataset

Synthetic OHLCV data generated with Geometric Brownian Motion
calibrated to real NSE price levels and historical volatility.

**Period:** 2021-04-26 to 2026-04-25 (~5 years, ~1250 trading days)

**Columns:** `Date, Open, High, Low, Close, Volume`
